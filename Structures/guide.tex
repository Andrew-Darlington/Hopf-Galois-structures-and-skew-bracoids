\section*{Directory Structure}

\begin{itemize}
    \item Files in the top-level directory include the Magma scripts \texttt{manager.m}, \texttt{workerA/B/C/D.m} and \texttt{attributes.m}.

    \item \texttt{computed-data/} contains \texttt{transgrps} directory, results files from structure classification of degrees 2--100, excluding 32, 48, 64, 80, 81 and 96, and a \texttt{Timings.log} file with the execution times of the computations.

    \item \texttt{results/} contains empty \texttt{transgrps} and \texttt{times} directories for storing results from structure classification.

    \item \texttt{logs/} stores the log files from the runs.
\end{itemize}

For a guide to the stored data, see: 

\url{https://github.com/Andrew-Darlington/Hopf-Galois-structures-and-skew-bracoids/blob/main/Structures/format-of-data.pdf} 

\section*{Usage Instructions}

\subsection*{1. Setup}

See the \texttt{README.md} file in \texttt{Enumerations} for comment on the manager/worker environment used by Magma. Ensure the host name and ports are set correctly in the manager and worker files, and set the number of workers in \texttt{manager.m}.

\subsection*{2. Running the Main Script}

The main script is \texttt{manager.m}. For a given degree $n$, this can be run interactively as follows:

\begin{verbatim}
% magma manager.m

NumAll (n);
\end{verbatim}

The main results are stored in \texttt{results/Results-n}. The corresponding list of transitive subgroups is stored in \texttt{results/transgrps/Grps-n}.

\subsection*{3. Running Over a Range}

If you wish to run over a range of values for $n$, then uncomment the code at the end of \texttt{manager.m} and edit accordingly.

\subsection*{4. Shell Scripts}

The directory contains two shell scripts which require execute permission:

\begin{itemize}
    \item \texttt{delete-jobs} --- deletes all Magma jobs which were started in this directory.

    \item \texttt{replace old-string new-string} --- replaces a string (e.g.\ machine name) in \texttt{manager*.m} and \texttt{worker*.m}.
\end{itemize}

\subsection*{5. Standard serial run}

For a standard serial run (ignoring parallel option), we provide {\tt 
	serial-run.m}.

To process degree {\tt n}, run {\tt NumAll(n)}.

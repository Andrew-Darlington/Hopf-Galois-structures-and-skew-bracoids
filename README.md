This repository contains code related to the preprint:

"Constructing Hopf--Galois structures and skew bracoids of small degree"

Authors: Andrew Darlington and E.A. O'Brien 

The repository contains two subdirectories:

1/ Enumeration -- code related to enumeration algorithm from preprint 

2/ Structures  -- code related to structures / classification algorithm from prepreprint 

Each has a README which gives basic information on how to use the related code.

We assume the following:

a/ code runs in a Linux environment 

b/ the user can run bash shell scripts; 

c/ availability of python3 for some of the auxiliary files.
